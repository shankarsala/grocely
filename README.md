# 🛒 Grocely

A production-inspired grocery delivery platform built using the PERN Stack.

> **Project Status:** 🚧 Under Development

This project is being developed step by step to learn and implement real-world full-stack development concepts, including authentication, REST APIs, PostgreSQL, payment integration, role-based access control, and live order tracking.

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- React Router
- TypeScript

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### Additional Technologies
- JWT Authentication
- Stripe
- Inngest
